# Projeto-Integrador-VI-A
Projeto integrador do curso de **Analise e Desenvolvimento de Sistemas** sobre aplicação de um processo de implementação de uma aplicação para dispositivos móveis.

O aplicativo **Brick Braker** será desenvolvido em **Flutter** (Dart), com arquitetura **MVC**, e entregue como **APK** Android.

---

## Download do APK
Para baixar e testar a versão mais recente do aplicativo no seu dispositivo Android sem precisar compilar o código:

1. Acesse a seção de [Releases do Projeto](https://github.com/Gian-Moreira/Projeto-Integrador-VI-A/releases/tag/v1.0.0)
3. Clique em **`Brick_Braker.apk`** para fazer o download.
4. Instale o arquivo no seu smartphone Android.
